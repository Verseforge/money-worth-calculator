# 这笔钱值多少？

一个轻量的金额感知小工具。  
输入一笔金额，把它换算成奶茶、通勤、外卖、电影票、生活日用、礼物人情等日常消费参照，帮助你更直观地理解这笔钱在生活里的分量。

## 功能

- 单项等价换算：看看这笔钱分别约等于多少份某个东西
- 组合换算：把金额拆成一组更具体的日常消费组合
- 按类型 / 按价格 / 按预算筛选参照
- 自定义标签、单价、量词和分类
- 预算参照：生活费、工资、存款占比
- 四种总结语气：轻松种草、冷静劝退、理性权衡、客观换算
- 支持导出结果图片

## 技术实现

本项目使用 React + Vite 构建，并通过 GitHub Actions 自动部署至 GitHub Pages。网页中的筛选、组合换算、自定义参照、预算比较与图片导出等交互均在浏览器本地完成，不涉及后端服务或用户数据上传。
